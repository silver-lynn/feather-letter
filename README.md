# 羽毛信 · 候鸟迁徙月历

一个零依赖的静态网页原型，用月份滑杆展示 20 种与中国相关的代表性候鸟在一年中的大致迁徙位置与方向。

## 本地预览

直接打开 `index.html`，或在目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据口径

- 当前版本为多年资料归纳的月份基线，不是实时定位。
- 地图节点为区域级示意，未公开珍稀物种的精确停歇点或巢址。
- 同一物种可能包含不同种群和迁徙策略；页面展示的是便于公众理解的代表路线。
- 后续应逐物种补充可追溯的数据版本、研究 DOI、种群范围与不确定性。

主要参考入口：Movebank、eBird Status & Trends、BirdLife DataZone、EAAFP，以及公开发表的中国候鸟追踪研究。

## 视觉方向评审

打开 `concepts.html` 可比较三套地图与鸟类内容排版，并查看东方白鹳、勺嘴鹬、北京雨燕、斑头雁四种试做鸟类的照片、原创插图与专属图标。

图片及地图授权见 `assets/ATTRIBUTION.md`。

`maps.html` 使用“观测密度”视觉方向和 GBIF 公开观测记录生成月份鸟群分布。地图默认聚焦中国及附近，只有当月聚合记录越出该区域时才自动扩图。所有物种均使用飞行姿态的无边框鸟群图标。生成脚本为 `scripts/build_gbif_flows.py`；鸟群表示聚合记录强弱，不代表真实种群数量。

用户可在地图右上角切换所在地。当前提供上海、北京、哈尔滨、青岛、厦门、广州、武汉、成都、昆明、西安、乌鲁木齐和拉萨，所在地会保存在当前浏览器中，并控制地图上的冷色晕染中心。

当前地图已扩展至 20 种候鸟、240 个“物种 × 月份”数据切片。新增开放授权照片的下载脚本为 `scripts/fetch_commons_photos.py`，署名信息见 `assets/data/photo-credits.json`。
